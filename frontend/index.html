Generador de horarios con algoritmos geneticos

Esta base del proyecto organiza el backend, el frontend y el motor genetico para construir horarios sin choques de docentes, aulas y grupos.

Como se aplican los algoritmos geneticos

  1. Cada individuo representa un horario completo.
  2. La funcion de fitness castiga conflictos y premia mejores distribuciones.
  3. Seleccion, cruce y mutacion mejoran la poblacion por generaciones.
  4. El sistema devuelve el mejor horario encontrado.
