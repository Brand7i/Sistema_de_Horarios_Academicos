PASOS PARA EJECUTAR

1) Abrir la carpeta en VS Code.

2) Backend:
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m app.seed
uvicorn app.main:app --reload

3) Frontend:
Abrir otra terminal.
cd frontend
npm install
npm run dev

4) Abrir:
http://localhost:5173

5) API:
http://127.0.0.1:8000/docs
